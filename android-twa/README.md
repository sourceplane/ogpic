# Rondo Android APK (Trusted Web Activity)

This directory builds an Android APK that wraps the **live** Rondo web app in a
[Trusted Web Activity](https://developer.chrome.com/docs/android/trusted-web-activity)
(TWA). The UI is loaded online from production — nothing is bundled — so the
installed app always shows the currently-deployed UI:

- Launch URL: `https://ogpic-web-console-next-prod.rahulvarghesepullely.workers.dev/rondo`

## Get the APK (no local setup)

The APK is built by GitHub Actions and attached to a GitHub Release.

1. Go to **Actions → "Android APK (TWA)" → Run workflow** (or push an `apk-*` tag).
2. When it finishes, download `rondo-twa.apk` from the **`twa-latest`** Release
   (or the build artifact on the run).
3. On your Android phone: open the APK, allow "install unknown apps" for your
   browser/files app when prompted, then install.

## Notes

- **Address bar:** each CI build generates a throwaway signing key, so the TWA
  cannot pass Digital Asset Links verification and Chrome shows a thin address
  bar. That is expected and does not affect testing the UI. To make it
  bar-less, sign with a stable keystore and serve
  `/.well-known/assetlinks.json` from the web app with that key's SHA-256
  (printed in the build log).
- **Requirements on device:** Android with Chrome (or another Custom
  Tabs / TWA provider) installed.
- `twa-manifest.json` holds the app identity (name, package id, colors, launch
  URL, icon). The Android project itself is generated by Bubblewrap at build
  time and is not committed.

## Build locally (optional)

Requires JDK 17 and the Android SDK.

```bash
npm install -g @bubblewrap/cli@1.22.0
cd android-twa
keytool -genkeypair -v -keystore android.keystore -alias android \
  -keyalg RSA -keysize 2048 -validity 10000 -storepass rondotwa -keypass rondotwa \
  -dname "CN=Rondo TWA, O=Sourceplane, C=US"
BUBBLEWRAP_KEYSTORE_PASSWORD=rondotwa BUBBLEWRAP_KEY_PASSWORD=rondotwa \
  bubblewrap build --skipPwaValidation
# → app-release-signed.apk
```
